## Основные проекты

### 1. Роботизированная система для сварки — обнаружение арматуры и манипуляция

Проект роботизации операций с арматурой с использованием компьютерного зрения и роботизированного манипулятора.

Система объединяет обработку изображений, алгоритмы компьютерного зрения и ROS 2 для обнаружения арматурных стержней и определения их геометрических характеристик, необходимых для последующих роботизированных операций.

**Основные компоненты:**
- Обнаружение арматуры с помощью компьютерного зрения.
- Сегментация изображений на основе DeepLabV3Plus.
- Скелетизация изображений и RANSAC для геометрической обработки.
- Интеграция с ROS 2 и Gazebo.
- Работа с планированием движения и роботизированной манипуляцией.

**Технологии:** Python, C++, ROS 2 Jazzy, Gazebo Harmonic, OpenCV, DeepLabV3Plus, RANSAC, Intel RealSense D435, MoveIt 2.

### 2. FeBot — мобильная робототехническая платформа с манипулятором

Проект робототехнической платформы, объединяющей управление мобильным роботом, работу с манипулятором, компьютерное зрение и большие языковые модели.

Одна из ключевых задач — научить робота интерпретировать команды на естественном языке и преобразовывать их в последовательность действий. Например, команда «принеси яблоко» может быть разбита на поиск объекта, перемещение к нему, захват и возвращение.

**Мой вклад включал:**
- Разработку программного обеспечения и интеграцию компонентов ROS 2.
- Работу с мобильной платформой и роботизированным манипулятором.
- Обучение и интеграцию LLaMA 3.1 8B для разложения естественно-языковых команд на действия.
- Разработку функций компьютерного зрения на OpenCV.
- Интеграцию программного обеспечения с симуляцией и реальным оборудованием.
- Разработку и тестирование сценариев навигации и манипуляции.

**Технологии:** Python, C++, ROS 2, LLaMA 3.1 8B, OpenCV, Gazebo, RViz, URDF, Linux, Docker.

### 3. IT Security Digest — веб-приложение для создания дайджестов по информационной безопасности

Веб-приложение для сбора новостей и публикаций по информационной безопасности, анализа материалов с помощью большой языковой модели и формирования структурированных дайджестов.

Система собирает публикации из профильных источников, обрабатывает статьи, устраняет дубликаты и использует LLM для суммаризации, классификации и оценки актуальности материалов. Результаты можно сохранять в виде отчётов.

**Основные возможности:**
- Сбор публикаций из источников по информационной безопасности.
- Обработка статей и устранение дубликатов.
- Анализ, классификация и суммаризация с помощью LLM.
- Асинхронная обработка запросов.
- Работа с базой данных PostgreSQL.
- Формирование дайджестов в форматах Markdown и DOCX.

**Технологии:** Python, FastAPI, asyncio, SQLAlchemy, PostgreSQL, Alembic, Pydantic, Docker, GigaChat API.
